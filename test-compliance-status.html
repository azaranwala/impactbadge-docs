Overall FERPA: PARTIAL. Application logic enforces correctly, but Firestore rules do not. A school admin with direct Firestore access could query all students across schools.

Fix required — add to firestore.rules:

match /users/{uid} {
  allow read: if isOwner(uid) ||
    (isTeacherOrSchoolAdmin() &&
     get(/databases/$(database)/documents/users/$(request.auth.uid)).data.schoolName
     == resource.data.schoolName);
}
