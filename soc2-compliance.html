2. Trust Service Criteria Mapping

CC1: Security (Common Criteria)

CriteriaCategoryImpactBadge ImplementationStatus
CC1.1 Security Firebase Authentication enforces identity verification for all users. Supports email/password, Google, Apple, and Clever SSO (OAuth 2.0). PASS
CC1.2 Security Firestore Security Rules enforce document-level access control. All reads/writes validated against authenticated user context. PASS
CC1.3 Security Role-based access control (RBAC) with 5 roles: student, org_admin, school_admin, teacher, parent. Role checked on every Cloud Function invocation. PASS

5. Authentication Methods

MethodProtocolDetails

Incident Response Procedures

  • Detection: Automated alerts via Cloud Monitoring and Crashlytics. Alert channels: email and mobile push.
  • Triage: Severity classification (P0-P3). P0 (data breach or full outage) triggers immediate response.
  • Containment: Affected Cloud Functions can be disabled within minutes via Firebase console. Firestore Security Rules can be updated to restrict access.
  • Notification: 72-hour breach notification to affected school districts per FERPA requirements. Notification includes: nature of breach, data affected, remediation steps, and point of contact.
  • Post-Incident: Root cause analysis documented. Preventive controls implemented. Affected parties notified of resolution.
